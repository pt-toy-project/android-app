# v3.7 달력 폭과 에브리타임 공개 시간표 가져오기

실제 기기에서 월간 달력이 좁은 열로 표시되어 날짜와 링이 겹치던 원인을 수정했습니다. `RecyclerView` 헤더를 부모와 함께 inflate해 `MATCH_PARENT` 폭을 유지합니다. 393dp 화면·큰 글씨·다크 모드 렌더링에서 달력 일곱 칸과 날짜가 분리되어 보이는 것을 확인했습니다.

시간표 화면의 **에타 시간표 가져오기**에서 에브리타임 시간표 공유 URL을 붙여넣고, 공개된 수업을 미리 본 뒤 현재 시간표에 추가할 수 있습니다. 실제 공유 페이지의 정적 HTML에는 수업이 없고 페이지 JavaScript가 공개 시간표 요청으로 수업을 채웁니다. 앱은 URL의 형식을 확인한 뒤 해당 공개 요청을 한 번 보내며, 로그인·쿠키·비밀번호는 사용하지 않습니다. 수업 시간의 5분 단위와 월요일=0 표시를 로컬 시간표 형식으로 변환합니다. 시간 미정 수업은 미리보기에서 제외 수를 알립니다. 취소하거나 실패하면 기존 수업이 바뀌지 않고, 확인하면 중복 수업을 건너뛰며 공유 링크와 수업을 같은 DB 트랜잭션에 저장합니다. CSV·직접 입력도 유지합니다.

공유 페이지의 HTML과 JavaScript 구조는 확인했습니다. 클라우드 네트워크가 `api.everytime.kr` 연결을 403으로 차단해 **실제 공개 API 응답과 휴대폰에서의 가져오기 성공은 검증하지 못했습니다.** 공개 페이지의 JavaScript 구조에 맞춘 XML 회귀 테스트를 추가했으며, 응답 형식이 달라지거나 서버가 요청을 거절하면 앱이 오류를 안내하고 기존 시간표를 보존합니다. 서버에 반복 요청하지 않고 사용자가 가져오기를 누를 때만 요청합니다.

검증: JVM 162개·SQLite 22개 통과, lint 오류 0개. 앱 APK와 기기 테스트 APK를 빌드했으며 기기 테스트 APK는 실행하지 않았습니다.

DB 스키마는 v4 그대로이며 기존 루틴·날짜별 완료·코인·아이템·설정·시간표와 백업 형식은 변경하지 않습니다. 실제 기기 계측과 덮어쓰기 설치는 실행하지 않았습니다. 기존 v3.3 배포 APK의 서명은 클라우드 debug 키와 달라 삭제 없이 업데이트하려면 원래 서명 키로 재빌드해야 합니다.
