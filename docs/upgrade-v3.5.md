# v3.5 — 달력으로 돌아보는 실천

버전 3.5 / versionCode 8. v3.4의 계정 없는 시작·파일 백업·집중 타이머·알림 복구 개선을 포함합니다. 제공된 화면에서는 달력·목표별 탐색·실제 달성 기록을 참고했고, 밝은 회색 바탕과 흰 카드, 절제된 파란색, 넓은 여백으로 정리했습니다.

## 사용자 경험

1. **누르면 펼쳐지는 월간 달력**: 오늘과 나만의 계획에서 ‘월간 달력’을 누르면 월 전체의 실천 링을 표시합니다. 날짜 선택, 이전/다음 달, 오늘 복귀, 일간 복귀를 지원하고 회전 후 선택도 유지합니다. 아래에는 선택 날짜의 루틴 완료·세부 체크·획득 코인이 나옵니다. 링의 파란색은 완료, 보라색은 세부 체크입니다.
2. **다음 행동이 보이는 오늘**: 평소에는 간단한 주간 달력을 보여주고 다음 실천 카드를 위쪽에 배치합니다. 실행·일시정지·종료 상태의 집중 이어 가기는 달력보다 먼저 표시합니다. 타이머 종료는 완료나 보상을 발생시키지 않습니다.
3. **목표로 시작하는 탐색**: 공부·연구, 글쓰기·창작, 탐험·관찰을 누르면 관련 인물을 바로 찾습니다. 충돌하는 기존 검색·분야 필터를 초기화하고 목표를 회전 후에도 유지합니다. 전체 목표 목록과 이름·설명 검색도 그대로 제공합니다.
4. **실제 기록으로 얻는 통계와 배지**: 설정 또는 상단 더보기의 ‘통계와 배지’에서 실천한 날, 연속 일수, 누적 완료와 누적 획득 코인을 봅니다. 완료 1·10·30·100회에 따라 달성 상태를 표시하며 월간 기록으로 연결합니다. 배지는 기록에서 계산하므로 추가 코인을 지급하지 않습니다.
5. **편안한 화면**: 밝은 배경과 둥근 카드, 파란색 강조를 전체 화면에 적용했습니다. 다크 모드는 밝은 파란색과 어두운 카드를 사용합니다. 큰 글꼴에서는 달력의 수치를 세로로 배치하고 화면을 스크롤할 수 있습니다.

## 기록의 의미와 보존

- DB 스키마는 v3 그대로이며, 새로운 마이그레이션이나 백업 형식 변경이 없습니다. 기존 루틴·기록·코인·구매/적용·설정을 유지합니다.
- 달력은 ‘오늘 + 나만의 계획’의 전체 기록을 합산합니다. 같은 인물·습관·날짜의 완료는 한 번만 계산합니다. 세부 체크는 각 출처에 저장된 기록으로 계산합니다.
- 완료/코인/세부 체크는 실제 저장 기록입니다. 삭제한 루틴의 과거 기록도 남습니다. 월간 합계는 페이지로 나눈 이력 목록을 사용하지 않아 100개가 넘는 완료도 포함합니다.
- 예정 수는 현재 루틴 설정을 기준으로 합니다. 과거 일정 변경 이력을 저장하는 기능은 없으므로 과거 당시의 정확한 목표 달성률은 아닙니다. 이 기준은 달력 아래에도 표시합니다.
- 연속 일수는 완료 또는 세부 체크가 있는 날을 셉니다. 오늘 아직 기록이 없다면 어제까지의 연속 기록을 보여주고, 빈 날을 만나면 끊습니다.
- 통계의 획득 코인은 누적 금액이며 현재 지갑 잔액과 구분합니다. 이전 버전의 샘플 기록에는 소급 보상을 지급하지 않습니다.
- Google 연결 코드는 보존합니다. 이번 기능은 계정·서버·유료 서비스 없이 동작합니다.

## 검증

준비된 클라우드 환경에서 다음 명령을 실행했습니다. 의존성 캐시를 사용하는 `--offline` 외에는 요청한 네 가지 Gradle 작업을 그대로 실행했습니다. 테스트 실패를 숨기거나 테스트를 비활성화하지 않았습니다. 화면 검증 중 발견한 월간 행 간격 오류와 목표 추천 클릭 오류를 수정하고 회귀 테스트를 유지했습니다.

```bash
bash /workspace/.android-cloud/install.sh --activate-only
source /workspace/.android-cloud/env.sh
cd /workspace/android-app
bash gradlew --offline --no-daemon --console=plain --max-workers=4 \
  :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest
python3 scripts/verify_database.py
```

실제 Android View의 Robolectric 렌더링 파일은 `app/build/verification-screens/`에 생성됩니다. 일반 달력·일간 실천·배지와 320dp 폭·글꼴 200%·다크 모드를 포함합니다. 이 결과는 실제 기기의 OS 알림·TalkBack·스피커·진동·Doze 검증을 대신하지 않습니다.

## 남은 조건

- 클라우드에서 실제 기기 계측 실행은 미실행입니다. 현재 머신에는 `/dev/kvm`이 없고 ADB 기본 사용자 디렉터리도 읽기 전용입니다. 기기 테스트 APK 빌드와 실행을 구분합니다.
- 기존 배포 v3.3과 현재 클라우드 디버그 인증서가 다릅니다. 기존 설치본 위에 업데이트하려면 동일한 배포 키로 빌드한 후 실제 데이터 보존 설치를 검증해야 합니다. 기존 사용자 앱을 삭제하지 마세요.
- 소셜 기능이나 유료 구독 없이 로컬 실천 흐름을 제공합니다. Google 등록은 필수 조건이 아닙니다.
- 기기 검증과 업데이트 배포 준비에 필요한 구체적인 다음 작업은 [다음 작업 프롬프트](next-upgrade-prompt.md)에 정리했습니다.
