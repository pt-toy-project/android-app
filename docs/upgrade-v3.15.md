# v3.15 시간표 사용성 개선

수업이 한두 개뿐이어도 시간표가 저녁까지 길게 이어져 개인 계획이 화면 밖에 밀렸습니다. 이제 저장된 수업이 있는 시간대 주변만 보여 줘 빈 공간을 줄입니다. 수업이 많은 주에는 상단 ‘내 계획’ 목록 아이콘을 눌러 계획 카드로 바로 이동할 수 있습니다.

에브리타임 가져오기 오류와 완료 안내는 화면 아래 상태 문구와 함께 하단 안내로 즉시 표시합니다. 계정·수업·개인 계획·완료 기록과 DB 구조는 변경하지 않았습니다.

[짧은 시간표](screenshots/v3.15-timetable-plans.png) · [긴 시간표의 계획 바로가기](screenshots/v3.15-timetable-jump.png) · [빌드 정보](../downloads/v3.15-build-manifest.json)

실제 휴대폰 설치·기기 계측 테스트는 실행하지 않았습니다. 기존 배포 v3.3과 테스트 APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱과 데이터를 삭제하지 마세요.
