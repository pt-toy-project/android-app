# v3 UI 전면 개편의 검증 범위

이번 작업은 승인된 30명·HeroDay·DB v2를 재사용하며 화면과 편집 동작을 개편했다. 인물 추가/제외는 이번 후속 작업에서 없다. 기존 신규 15명과 제외 2명의 이유는 historical-sources.md를 유지한다.

- 오늘/개인 계획은 TimelineActivity의 source 구분과 별도 시작 레이아웃을 사용한다. 헤더와 행이 한 RecyclerView에서 스크롤한다.
- 개인 계획 직접 작성은 기존 user_routines의 PERSONAL로 저장한다. 새 계획만 personal + manual_UUID 식별자를 사용한다. 기존 인물/템플릿/루틴 ID는 변경하지 않는다.
- DB 스키마 버전은 2로 유지한다. schema_v1.sql, schema_v2.sql, migration_1_2.sql을 변경하지 않았다.
- 하루 시작/완료/구매/이력의 원자성과 중복 지급 보호는 기존 저장소를 유지한다. UI에서 다른 출처나 다른 날짜의 오래된 완료 동작을 차단한다.
- 시간·요일·활성/알림 상태를 바텀시트에서 편집하고, HERO_DAY는 사용자 설정만 변경하며 개인 계획은 제목도 편집한다. 기록의 과거 제목은 다시 쓰지 않는다.

## 실행 테스트

Robolectric 4.16.1/Android 35에서 Activity와 View를 생성하고 실제 버튼을 클릭한다. 화면 테스트는 source 코드를 실행하며 단순 XML 문자열 검사나 목업 데이터 반환으로 대체하지 않는다. SQLiteOpenHelper와 AppRepository를 실행해 실제 v1 파일 업그레이드, ID 41/제목/시간/요일/알림/완료 스냅샷/잔액 80/보유·적용 칭호를 비교한다. 하루 재시작과 두 출처 간 중복 보상, 실패 주입 롤백을 검증한다.

Native Graphics에서 오늘(빈 상태/채택 상태/완료 후), 인물 목록, 개인 계획, 하루 미리보기, 200% 글꼴 캡처를 생성한다. 캡처 파일은 빌드 결과에만 있으며 APK에 넣지 않는다. 완료 후 진행률과 잔액이 갱신되는 것도 테스트한다.

추가 테스트 의존성은 앱에 포함되지 않는 Robolectric이다. Maven POM과 공식 LICENSE를 실제 HTTP 200으로 확인했고 MIT 라이선스 전문을 docs/test-licenses에 보관한다. 신규 런타임 라이브러리·외부 폰트·이미지는 없다.

자료 URL 47개를 이번 환경에서 다시 실제 요청했고 전부 curl(56) CONNECT 403으로 실패했다. source-access-ui-overhaul.json에 결과를 보관한다. 이는 서버 본문을 읽었다는 뜻이 아니며 네트워크 초안/정책을 바꾼 작업도 없다.

## 남은 범위

실제 휴대전화 설치/업데이트, TalkBack, Android OS 알림 수신/권한/재부팅, 제조사별 최대 글꼴, 실기기 프레임·메모리 측정은 미실행이다. 시뮬레이션 View/DB 실행과 기기 실행을 구분한다. 초기 v2 인증서의 개인 키는 여전히 없어 v2 업데이트 호환을 주장하지 않는다. 현재 v3 인증서는 유지한다.

최종 테스트 수·APK SHA-256·대응 소스는 downloads/v3-build-manifest.json을 따른다.

## 최종 확인

전체 명령 성공: JVM 92개(기존 75 + 새 실행 테스트 17), SQLite 19개, 앱·계측 APK 빌드. 실패·오류·스킵 0. 예제 산술 테스트 1개는 기능 검증 근거에서 제외합니다. Lint 오류 0·경고 123이며 미사용 기존 자원/스타일/의존성 안내를 포함합니다. 테스트나 lint를 비활성화하거나 회피 설정을 추가하지 않았습니다.

사진 15장 636,640 B와 기존 아바타 414 B는 원본 바이트 그대로입니다. 이번 사진·아바타 리소스 용량 증가 0 B입니다. 앱 이미지 크레딧 HTML과 docs/image-credits.md도 그대로입니다. 인물 30명·템플릿 59개·하루 블록 240개의 ID와 버전별 SQL은 바이트/식별자 비교로 보존을 확인했습니다.

현재 v3 인증서 SHA-256은 bf3489b7cb1b71f6f452b1e3caea6859e29365b69a37d5d8680c536dc5f81c4c로 유지합니다. 이전 v2 인증서의 키는 없어 v2 업데이트 설치를 보장하지 않습니다. 실제 기기 테스트 50개는 컴파일만 확인했고 미실행입니다.
