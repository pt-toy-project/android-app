# v3.6 시간표와 홈 화면 위젯

기존 루틴과 독립된 주간 시간표를 추가했습니다. 하단 **시간표**에서 수업 이름·요일·시작/종료·강의실·담당자를 입력하고 주간 표 또는 목록으로 볼 수 있습니다. 겹친 수업은 나란히 표시하고, 오늘과 다른 주로 이동할 수 있습니다. 오늘 화면에는 오늘 수업 요약과 시간표 진입 버튼이 보입니다. 시간표 수업 추가·조회·시간 경과는 루틴 완료나 코인을 발생시키지 않습니다.

**홈 화면에 시간표 추가**를 누르면 지원하는 런처의 위젯 추가 창을 열고, 그렇지 않은 기기에는 홈 화면의 위젯 목록에서 추가하는 방법을 보여 줍니다. 위젯은 현재/다음 수업과 강의실을 표시하고 누르면 시간표를 엽니다. 첨부된 삼성 알림창에는 홈 위젯 대신 Android 알림 카드가 표시됩니다. 시간표 화면에서 **알림창에 시간표 표시**를 직접 켜야 하며, 알림 권한이나 채널이 꺼져 있으면 설정 진입 버튼을 보여 줍니다. 수업 시작·종료와 날짜 변경 시 표시를 갱신하도록 예약합니다. 실제 런처와 알림창 동작은 기기 검증이 필요합니다.

에브리타임 공유 URL은 시간표 화면에서 저장·열거나 Android 공유 메뉴로 받을 수 있습니다. 이 버전은 공유 링크에서 수업 데이터를 자동 추출하지 않습니다. 이 앱의 UTF-8 CSV 형식으로 수업을 가져오거나 내보낼 수 있고, 빈 파일 내보내기를 양식으로 쓸 수 있습니다. 공유 링크가 가리키는 개인 수업 내용은 앱 패키지·저장소에 넣지 않았습니다.

DB v3→v4 마이그레이션은 `timetable_entries`만 추가합니다. 기존 루틴·완료·코인·구매·설정과 계정 연결 코드는 유지합니다. v4 파일 백업에는 수업과 저장한 공유 링크가 포함됩니다. v3 백업을 복원할 때는 현재 시간표·링크·알림 설정을 보존합니다. 동일 수업 CSV를 다시 가져오면 중복 추가하지 않습니다.

검증: `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest` 및 `python3 scripts/verify_database.py` 통과. JVM 159개·SQLite 22개 통과, lint 오류 0개(경고 185개). UI는 Robolectric의 320dp 다크 모드·큰 글씨에서 렌더링했습니다. `assembleDebugAndroidTest`는 기기 테스트 APK 빌드이며 기기 테스트 실행은 아닙니다. 기존 v3.3 배포본과 현재 클라우드 debug 키의 서명이 달라 업데이트 설치는 확인되지 않았습니다. 기존 앱과 데이터를 삭제하지 마세요.
