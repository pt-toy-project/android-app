# v3.12 주간 시간표 우선 배치

시간표 탭을 열면 수업 격자보다 요약과 버튼, 주 이동, 다음 수업 안내가 먼저 보여 수업을 바로 보기 어려웠습니다. 이제 요일·시간 격자를 맨 앞에 두고 수업 도구는 그 아래로 옮겼습니다. 기본 화면 폭에서는 월~토를 한 번에 볼 수 있으며 일요일은 좌우로 밀어 볼 수 있습니다. 요일 머리글은 시간대를 위아래로 밀어도 남습니다.

수업은 날짜별 기록이 아니라 매주 같은 요일·시간에 반복 저장됩니다. 그래서 주 이동과 날짜 숫자를 제거했고, 목록 보기에도 ‘월요일’처럼 요일만 표시합니다. 수업 추가, 에브리타임 공개 링크, CSV, 위젯, 알림은 그대로 사용할 수 있습니다. ‘오늘’ 화면의 날짜별 루틴·완료 기록과 시간표 DB는 변경하지 않았습니다.

Robolectric에서 [처음 열린 주간 표](screenshots/v3.12-timetable-first-night.png), [요일별 목록](screenshots/v3.12-timetable-list-night.png), [가져오기 미리보기](screenshots/v3.12-import-preview-night.png)를 렌더링했습니다. 전체 JVM·SQLite 검사와 lint, 앱·기기 테스트 APK 빌드 결과는 [빌드 정보](../downloads/v3.12-build-manifest.json)에 있습니다. 실제 휴대폰 화면·업데이트 설치·기기 계측 테스트는 실행하지 않았습니다.

기존 배포 v3.3 APK와 클라우드 debug APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱이나 데이터를 삭제하지 마세요.
