# 위인의 하루 v3 화면 개편 기준

## 화면 구조

| 화면 | 이전 구조 | 개편 구조 |
|---|---|---|
| 오늘 | 인물 선택/미리보기/요약/관리 버튼이 한 화면에 혼재 | 오늘의 날짜·진행·다음 실천·시작한 인물의 타임라인. 비어 있으면 인물 탐색 CTA 하나 |
| 인물 | 검색과 드롭다운·큰 설명·세로 사진 카드 | 검색 필드·가로 분야 칩·48dp 원형 사진/기본 아바타·이름과 분야 두 줄 |
| 하루 상세 | 긴 소개/출처/크레딧과 여러 버튼이 본문에 반복 | 인물 요약·8블록 미리보기·고정된 하루 시작 버튼. 긴 이야기·근거·크레딧은 접기 |
| 나만의 계획 | 인물의 실천에서만 개별 채택 | 개인 계획 직접 작성·기존 계획·인물에서 개별 가져오기. HERO_DAY와 조회/편집 분리 |
| 편집 | 큰 시계·체크박스가 임시 대화상자에 표시 | 제목·시간 선택·반복 요일 칩·활성/알림 스위치·검증 오류가 있는 바텀시트 |
| 기록 | 긴 한 문장 기록·96dp 이전 기록 상자 | 제목/날짜/인물/포인트 카드·30개씩 읽기·이전 기록 접기 |
| 상점 | 동적으로 조합한 단순 텍스트 카드 | 잔액/현재 칭호·동일 규격 구매/적용 카드. 기존 아이템과 가격 유지 |
| 설정·크레딧 | 화면마다 다른 경로/표제 | 공통 툴바의 기록·설정·크레딧 메뉴와 뒤로가기. 기존 내용과 권한 동작 유지 |

하단 탭은 오늘 / 인물 / 나만의 계획 / 상점이다. 주 화면 하나당 한 목적을 둔다. 오늘에서 새로운 하루를 선택하려면 인물 화면으로 이동한다. 기존 채택이 없어도 빈 화면 CTA가 실제 인물 탐색을 연다.

## 글과 디자인

목록과 타임라인은 제목 한 줄 + 보조 한 줄을 기본으로 한다. 날짜/상태/근거 칩은 짧은 메타데이터다. 긴 설명은 인물 이야기 또는 근거 바텀시트에서 읽는다. 신규 계획은 제목·시간·요일·알림 설정으로 설명하며 역사 인물로 오인 표시하지 않는다.

청록색 하나와 중립 배경/글자/테두리를 사용한다. 일관된 20dp 바깥 여백, 16~20dp 카드 패딩, 20dp 모서리, 48dp 이상의 터치 영역을 둔다. 주간과 야간 팔레트를 분리한다. 선택한 날짜는 팔레트의 on-primary 글자를 사용한다.

fontScale 1.3 이상에서 제목/보조의 줄 제한과 말줄임을 해제한다. 200% 글꼴에서 날짜 항목 폭과 하단 탐색 높이를 늘리고 탐색 라벨의 여러 줄 표시를 허용한다. 헤더를 RecyclerView의 ConcatAdapter 항목으로 넣어 큰 글꼴에서도 화면 전체가 함께 스크롤한다. 이 변경에 메모리 절감률을 부여하지 않는다.

## 인물 사진과 이미지 제외

Wikimedia Commons 사진 15장, 기본 벡터 아바타, 기존 이미지 크레딧 파일은 변경하지 않았다. 사진은 표시 단계에서 비율을 유지해 가운데를 맞추고 원형으로 그린다. JPEG를 다시 저장하지 않는다. 신규 인물은 기존 자체 제작 기본 아바타를 쓴다. AI 이미지 생성·도구/약관 조사·프롬프트·시안 단계는 이번 범위에 없다.

검증용 화면 PNG는 app/build/verification-screens에만 생성한다. 앱의 이미지 리소스나 APK에 포함하지 않는다. 캡처는 Android 35 Robolectric Native Graphics 렌더링이며 실제 휴대전화 화면이라고 주장하지 않는다.

## 실제 실행한 범위

Robolectric에서 Activity/레이아웃을 실제 생성하고 클릭 핸들러를 실행했다. 인물 탐색·검색·분야 필터·8블록 미리보기·근거 바텀시트·하루 전체 채택·개인 계획의 입력 오류와 저장·크레딧 접근을 검증한다. 저장된 데이터를 읽어 개인/인물 출처 분리와 완료 한 번의 10코인 보상을 확인한다.

주간/야간 화면 로딩, 글자/배경 대비 계산, 200% 글꼴의 줄 제한 해제와 탐색 높이, 원형 사진의 모서리 투명도를 자동 검증한다. Native Graphics 캡처를 눈으로 검토한다. TalkBack의 실제 발화·제조사별 최대 글꼴·실제 야간 디스플레이·OS 알림·실제 업데이트 설치는 기기 실행이 없어 미실행이다.

근거 표시는 기록 / 재구성 / 현대 적용이다. 현재 자료 접근 47개는 CONNECT 403으로 본문 재확인에 실패했고 모든 하루 블록은 현대 적용이다. 시간은 알림 제안과 자료 시간대를 분리한다. 안내는 화면마다 한 번만 표시한다.
