# v3.0 화면 구조와 문구

| 영역 | v2 | v3 |
|---|---|---|
| 하단 | 홈 / 루틴 / 위인 / 상점 / 설정 | 오늘 / 인물 / 나만의 계획 / 상점 |
| 오늘 | 요약 카드·긴 소개·다음 루틴 | 시작한 모든 인물 하루의 시각순 타임라인·진행/잔액·완료/설정 상세 |
| 인물 | 2열·큰 사진·분야·연대·개수 | 1열·48dp 원형 아바타·이름 한 줄·분야 한 줄·검색/필터 |
| 미리보기 | 기록·실천·출처 전문이 카드에 노출 | 8블록·제목/시각/근거 칩·자세히·하루 시작 |
| 개인 계획 | 인물별 개인 채택 | PERSONAL 전체 목록·개별 실천 추가·편집, HERO_DAY와 분리 |
| 설정/기록/크레딧 | 설정 탭·기록 버튼·크레딧 | 오늘/개인 계획의 설정·기록 버튼, 설정의 기존 크레딧 경로 |

문구는 짧은 제목 + 보조 한 줄을 기본으로 합니다. fontScale 1.3 이상에서는 제목/보조의 maxLines를 풀고 ellipsize를 제거합니다. 고정 높이 텍스트를 사용하지 않으며 전체 내용은 스크롤하고 하단 탭은 유지합니다. 달력 버튼은 48dp이고 버튼은 최소 48dp 터치 영역을 둡니다. 큰 글꼴의 버튼은 세로 배치합니다. 모든 목록·미리보기·상세에서 이름/상태/근거 등급을 글자로 알립니다. 출처와 긴 소개는 자세히 대화상자 또는 기존 상세 바텀시트에서 읽습니다.

기본 팔레트는 기존 보라/남색 포인트 한 계열과 중립 surface/text입니다. 상태는 색에 더해 완료/예정/중지/시간 지남 문구로 표시합니다. 주간·야간 테마를 유지하고 원형 사진은 clipToOutline로 화면 표시만 변경합니다. 이미지 바이트를 재저장하지 않습니다.

근거 라벨: 기록 / 재구성 / 현대 적용. 알림은 “제안 HH:mm”, 출처 시간대는 “v2 출처 시간대”로 구분합니다. 공통 안내: “기록에 없는 활동과 시각은 앱 제안입니다. 알림 시각은 직접 바꿀 수 있습니다.” 현재 자료 재확인이 차단되어 모든 v3 블록은 현대 적용입니다.

정적 확인: 텍스트 wrap_content, 큰 글꼴 줄 제한 해제, 터치 영역, 목록 읽기 라벨, DayNight 테마 연결을 코드에서 확인했습니다. TalkBack 탐색·최대 시스템 글꼴의 실제 화면·야간 대비 실측은 기기 미연결로 미실행입니다. 메모리 절감률·렌더링 성능 실측을 주장하지 않습니다.
