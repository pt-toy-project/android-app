# 위인의 하루 v3 화면 개편 기준

## 화면 구조

| 화면 | 이전 구조 | 개편 구조 |
|---|---|---|
| 오늘 | 인물 선택/미리보기/요약/관리 버튼이 한 화면에 혼재 | 오늘의 날짜·진행·다음 실천·시작한 인물의 타임라인. 비어 있으면 인물 탐색 CTA 하나 |
| 인물 | 검색과 드롭다운·큰 설명·세로 사진 카드 | 검색 필드·가로 분야 칩·48dp 원형 사진/기본 아바타·이름과 분야 두 줄 |
| 하루 상세 | 긴 소개/출처/크레딧과 여러 버튼이 본문에 반복 | 인물 요약·8블록 미리보기·고정된 하루 시작 버튼. 긴 이야기·근거·크레딧은 접기 |
| 나만의 계획 | 인물의 실천에서만 개별 채택 | 개인 계획 직접 작성·기존 계획·인물에서 개별 가져오기. HERO_DAY와 조회/편집 분리 |
| 편집 | 큰 시계·체크박스가 임시 대화상자에 표시 | 제목·시간 선택·반복 요일 칩·활성/알림 스위치·검증 오류가 있는 바텀시트 |
| 기록 | 긴 한 문장 기록·96dp 이전 기록 상자 | 제목/날짜/인물/포인트 카드·30개씩 읽기·이전 기록 접기 |
| 상점 | 동적으로 조합한 단순 텍스트 카드 | 잔액/현재 칭호·동일 규격 구매/적용 카드. 기존 아이템과 가격 유지 |
| 설정·크레딧 | 화면마다 다른 경로/표제 | 공통 툴바의 기록·설정·크레딧 메뉴와 뒤로가기. 기존 내용과 권한 동작 유지 |

하단 탭은 오늘 / 인물 / 나만의 계획 / 상점이다. 주 화면 하나당 한 목적을 둔다. 오늘에서 새로운 하루를 선택하려면 인물 화면으로 이동한다. 기존 채택이 없어도 빈 화면 CTA가 실제 인물 탐색을 연다.

## 글과 디자인

목록과 타임라인은 제목 한 줄 + 보조 한 줄을 기본으로 한다. 날짜/상태/근거 칩은 짧은 메타데이터다. 긴 설명은 인물 이야기 또는 근거 바텀시트에서 읽는다. 신규 계획은 제목·시간·요일·알림 설정으로 설명하며 역사 인물로 오인 표시하지 않는다.

청록색 하나와 중립 배경/글자/테두리를 사용한다. 일관된 20dp 바깥 여백, 16~20dp 카드 패딩, 20dp 모서리, 48dp 이상의 터치 영역을 둔다. 주간과 야간 팔레트를 분리한다. 선택한 날짜는 팔레트의 on-primary 글자를 사용한다.

fontScale 1.3 이상에서 제목/보조의 줄 제한과 말줄임을 해제한다. 200% 글꼴에서 날짜 항목 폭과 하단 탐색 높이를 늘리고 탐색 라벨의 여러 줄 표시를 허용한다. 헤더를 RecyclerView의 ConcatAdapter 항목으로 넣어 큰 글꼴에서도 화면 전체가 함께 스크롤한다. 이 변경에 메모리 절감률을 부여하지 않는다.

## 인물 사진과 이미지 제외

Wikimedia Commons 사진 15장, 기본 벡터 아바타, 기존 이미지 크레딧 파일은 변경하지 않았다. 사진은 표시 단계에서 비율을 유지해 가운데를 맞추고 원형으로 그린다. JPEG를 다시 저장하지 않는다. 신규 인물은 기존 자체 제작 기본 아바타를 쓴다. AI 이미지 생성·도구/약관 조사·프롬프트·시안 단계는 이번 범위에 없다.

검증용 화면 PNG는 app/build/verification-screens에만 생성한다. 앱의 이미지 리소스나 APK에 포함하지 않는다. 캡처는 Android 35 Robolectric Native Graphics 렌더링이며 실제 휴대전화 화면이라고 주장하지 않는다.

## 실제 실행한 범위

Robolectric에서 Activity/레이아웃을 실제 생성하고 클릭 핸들러를 실행했다. 인물 탐색·검색·분야 필터·8블록 미리보기·근거 바텀시트·하루 전체 채택·개인 계획의 입력 오류와 저장·크레딧 접근을 검증한다. 저장된 데이터를 읽어 개인/인물 출처 분리와 완료 한 번의 10코인 보상을 확인한다.

주간/야간 화면 로딩, 글자/배경 대비 계산, 200% 글꼴의 줄 제한 해제와 탐색 높이, 원형 사진의 모서리 투명도를 자동 검증한다. Native Graphics 캡처를 눈으로 검토한다. TalkBack의 실제 발화·제조사별 최대 글꼴·실제 야간 디스플레이·OS 알림·실제 업데이트 설치는 기기 실행이 없어 미실행이다.

근거 표시는 기록 / 재구성 / 현대 적용이다. 현재 자료 접근 47개는 CONNECT 403으로 본문 재확인에 실패했고 모든 하루 블록은 현대 적용이다. 시간은 알림 제안과 자료 시간대를 분리한다. 안내는 화면마다 한 번만 표시한다.

## 휴대폰 피드백 반영: 간결 화면 1013

저장소 첫 README의 다운로드 링크가 v2를 가리키는 오류를 수정하고 주 다운로드를 v3 한 개로 통일했다. 보존된 v2 안내는 별도 문서로 이동했다. 기존 v2 서명과 v3 서명 불일치는 UI 코드와 별개의 업데이트 제한이다.

인물 화면은 중복 제목·슬로건을 없애고 툴바에 실제 전체 인원 수를 표시한다. 목록은 이름·분야 두 줄이다. 하루 미리보기는 제목·제안 시간/종류, 근거 칩과 자세히 버튼만 표시한다. 설명·출처는 기존 바텀시트에 보존한다. 인물 소개에서 분야 옆 소개 문장을 제거하고 소개 버튼으로 옮겼다. 오늘의 반복 설명과 상태 글은 목록에서 숨기고 제목·시간, 짧은 근거 칩, 완료·설정 조작을 남긴다. 날짜 줄은 유지하며 날짜 버튼에서 날짜를 선택한다. 중복 주간 띠와 페이지 제목은 숨기고 진행 카드의 글꼴·여백을 줄였다. 큰 글꼴의 줄바꿈·상세 접근과 기존 데이터/설정은 유지한다.

오늘 상단과 설정에 `3.0 · 간결 화면 1013`을 표시한다. 인물 툴바는 `인물 · 30명`이다. 실제 사용자 휴대폰 설치 여부는 이 환경에서 확인하지 못한다.

## v3.1: 목표별 영웅과 서브 퀘스트

펠레는 사용자가 예시로 정정했으므로 신규 인물로 추가하지 않았다. 기존 30명은 공부·연구, 개발·문제 해결, 글쓰기·창작, 교육·돌봄, 기획·리더십, 탐험·관찰이라는 앱의 학습 목표로 찾을 수 있다. 이 분류는 역사 인물의 공식 현대 직업을 주장하지 않는다. 원래 분야 필터·검색도 유지하며 목표와 함께 적용한다.

240개 기존 블록 ID에 510개 고정 퀘스트 ID를 붙였다. 핵심 블록은 인물별 구체적인 관찰·풀이·창작·정리 행동 2~3개를 제공한다. 준비·집중·정리, 오후 학습 등 여러 세션을 표현하고 필요한 휴식을 안내한다. 기상에는 아침, 식사에는 점심, 휴식에는 저녁 식사를 넣었다. 기존 사용자가 저장한 블록 제목과 시간은 덮어쓰지 않으므로 이미 채택한 하루에서도 세부 항목으로 세 끼를 확인할 수 있다.

목록에는 제목과 `시간 · 인물 · 1/3 완료`를 표시한다. 실천 보기를 누르면 두 줄을 기본으로 한 체크 항목과 제안 분량을 표시한다. 미리보기는 체크하지 않고 실제 채택 후 날짜별로 저장한다. 긴 근거는 기본적으로 접고 ‘근거·출처 보기’로 펼친다. 현대 적용 칩과 ‘동작·시간·횟수는 앱 제안’ 안내를 유지한다. 모든 세부 동작·분량은 자체 작성한 MODERN이며 역사적 훈련법으로 표시하지 않는다.

오늘과 설정에서 `3.1 · 서브 퀘스트`, 인물에서 `인물 · 30명`으로 빌드를 식별한다. 실기기·TalkBack·실제 설치 검증은 별도로 구분한다.

## v3.2 시작·실행·기록 흐름

Google로 로그인 또는 계정 없이 시작 → 3단계 안내 → 인물 선택 → 오늘의 실천 시작 → 체크 → 계정과 백업으로 이어진다. 첫 안내는 건너뛸 수 있고 설정에서 다시 볼 수 있다. 실제 루틴 알림의 상세 연결은 안내로 막지 않는다. Google 미설정 상태는 준비 중으로 표시한다.

오늘의 대표 실천은 아래 목록에서 중복 표시하지 않고 관리에서는 전체 블록을 보인다. 대표 카드의 주 동작은 실천 시작, 보조 동작은 완료다. 목록의 근거·완료·상세는 한 행으로 묶고 큰 글꼴에서는 세로로 놓는다. 홈 버전 부제, 반복 카드, 설정의 긴 진단 문장을 줄였다. 설정은 내 기록·알림·도움말이며 진단 상세는 필요할 때 연다.

Google SDK 표준 로그인 버튼을 사용한다. 기존 인물 사진·아바타는 재사용하고 Google 프로필 사진은 가져오지 않는다. 200% 글꼴의 안내 진행과 화면 렌더링을 실행했으며 실제 기기 검증은 별도다. 상세 구현과 미실행 범위는 [experience-v3.2.md](experience-v3.2.md)를 참고한다.

하단 탭은 오늘(달력·체크), 인물(사람), 계획(목록), 상점(가방)의 앱 자체 작성 24dp 선 벡터로 통일했다. 외부 아이콘 파일과 인물 이미지는 새로 가져오지 않았다.

## 3.3 실천 중심 화면

- 목록: 시간 먼저/제목/근거·완료·실천보기 3칸에서 제목/보조 한 줄/근거·짧은 완료로 정리했다. 카드 탭이 세부 실천 진입이며 반복 버튼을 없앴다. 전체 카드와 완료 버튼의 접근성 라벨을 각각 유지한다.
- 실천 상세: 오늘의 활성 실천에서 집중 타이머를 연다. 타이머 화면은 실천 이름, 큰 남은 시간, 상태, 주 동작 하나와 다시 설정으로 구성한다. ‘실천 완료’와 ‘집중 시간 종료’를 구별한다.
- 홈: 진행 중인 타이머 복귀와 전체 완료 카드를 추가한다. 날짜/필터에 해당하는 일정이 전부 완료된 경우에만 오늘 완료를 표시한다.
- 설정: 알림 시험 버튼과 결과 한 줄을 추가한다. 예약 성공은 알림 도착이라는 표현을 쓰지 않는다. 정확한 알람 권한이 없을 때 지연 가능성을 표시한다.
- 뒤로/완료는 탭과 동일한 1.8단위 선 두께의 자체 제작 벡터를 사용한다. 인물 사진 파일과 크레딧은 그대로다.
