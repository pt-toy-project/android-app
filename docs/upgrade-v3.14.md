# v3.14 시간표 아래 내 계획

수업 격자 아래에 개인 계획 목록을 추가했습니다. 저장된 계획의 시작 시간과 반복 요일을 최대 세 개까지 보여 주며, 계획 추가 버튼은 기존 편집기를 열고 전체 보기 버튼은 개인 계획 화면을 엽니다. 개인 계획이 없으면 빈 상태를 안내합니다. 인물 탭과 수업 시간표는 그대로 유지합니다.

개인 계획은 종료 시간이 없어 수업 칸에 합치지 않았습니다. 수업 DB, 개인 계획 DB, 날짜별 완료 기록, 코인과 설정은 변경하지 않았습니다.

[화면 이미지](screenshots/v3.14-timetable-personal-night.png) · [빌드 정보](../downloads/v3.14-build-manifest.json)

실제 기기 설치·기기 계측 테스트는 실행하지 않았습니다. 기존 배포 v3.3 APK와 클라우드 debug APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱이나 데이터를 삭제하지 마세요.
