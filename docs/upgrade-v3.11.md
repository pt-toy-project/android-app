# v3.11 위젯·마이페이지·광고 영역

기존 홈 화면 위젯은 수업이 끝나면 ‘오늘 수업 끝!’만 보여 줘 앱의 ‘오늘의 시간표’ 카드와 달랐습니다. 이제 두 화면 모두 저장된 오늘 수업을 시간순으로 보여 줍니다. 2개 수업을 표시할 수 있는 크기에서는 시간·이름·강의실을 함께 보여 주고, 작은 위젯이나 큰 글씨에서는 첫 수업과 나머지 개수를 보여 줍니다. 위젯 크기를 바꿔도 다시 그립니다. 수업이 없는 날에는 빈 상태를 표시합니다.

설정 화면은 ‘마이페이지’로 정리했습니다. 계정 없이 사용 중이라는 상태, 기기 저장 안내, 파일 백업·복원과 진행 기록을 앞쪽에 두었습니다. 기존 알림·소리 스위치, 권한 안내, 미리보기, 자료 출처 연결은 유지합니다. 인물 추천 화면에는 광고 콘텐츠를 나중에 연결할 수 있는 영역을 만들었습니다. 디버그 APK에서만 명시적인 자리 안내가 보이고, 광고 SDK·광고 ID·추적·외부 링크는 아직 없습니다.

Robolectric에서 [마이페이지 기본 화면](screenshots/v3.11-settings-light.png)과 [다크 모드·큰 글씨](screenshots/v3.11-settings-large-font-night.png), [2개 수업 위젯 레이아웃](screenshots/v3.11-widget-two-classes-night.png), [추천 화면 광고 자리](screenshots/v3.11-ad-slot-night.png)를 렌더링했습니다. 위젯 캡처는 Android 뷰 레이아웃의 크기 검사이며 실제 Samsung 런처의 RemoteViews 표시 결과는 아닙니다. 전체 JVM·SQLite 검사와 lint, 앱·기기 테스트 APK 빌드 결과는 [빌드 정보](../downloads/v3.11-build-manifest.json)에 있습니다.

DB 스키마와 저장 데이터는 바꾸지 않았습니다. 실제 휴대폰에서 위젯 크기별 표시·기기 테스트·덮어쓰기 설치는 실행하지 않았습니다. 기존 배포 v3.3 APK와 클라우드 debug APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱이나 데이터를 삭제하지 마세요.
