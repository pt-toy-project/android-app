# v3.8 에브리타임 시간표 가져오기 오류 수정

v3.7에서 실제 휴대폰의 공유 링크가 “시간표 형식이 바뀌어 읽지 못했어요”로 실패했습니다. 같은 공개 링크에 앱과 동일한 HTTP 요청을 보내 확인한 서버 응답은 정상 XML이었습니다. 수업 정보는 예상한 구조였으므로 Android에서 지원 여부가 다른 데스크톱 `DocumentBuilderFactory` 보안 옵션을 사용하던 파서를 Android `XmlPullParser`로 교체했습니다. 외부 XML 선언은 읽기 전에 거부하며 응답 크기 제한과 입력 검증은 유지합니다.

확인한 응답의 구조에서 링크 식별자·수업명·교수명·강의실·사용자 정보를 모두 예시 값으로 바꾼 회귀 테스트를 추가했습니다. 실제 공개 응답의 요일·5분 단위 시간 및 시간 미정 수업을 반영하며, 시간표 외 계정·다른 시간표 목록은 가져오지 않습니다. Android 기기에서 같은 파서를 호출하는 계측 테스트도 추가했습니다.

서버 응답 수신과 JVM 회귀 테스트까지 확인했습니다. **수정 APK를 실제 휴대폰에 설치해 가져오기를 완료하는 검증은 아직 하지 못했습니다.** 수업 추가 전 확인 화면, 실패 시 기존 시간표 보존, 로그인 없는 직접 입력·CSV, 위젯과 알림창 기능은 유지합니다. DB 스키마는 v4 그대로이고 기존 루틴·기록·코인·아이템·설정·시간표에 마이그레이션이 필요하지 않습니다.

검증: JVM 163개·SQLite 22개 통과, lint 오류 0개·경고 184개. 앱 APK와 기기 테스트 APK를 빌드하고 앱 APK 서명을 확인했습니다. 기기 테스트 APK의 빌드와 실제 실행은 별개이며 실행하지 못했습니다. 세부 기록은 APK와 함께 배포한 [빌드 정보](../downloads/v3.8-build-manifest.json)에 있습니다.

기존 v3.3 배포 APK의 서명은 클라우드 debug 키와 다릅니다. v3.8 테스트 APK를 v3.3 위에 덮어쓰기 설치할 수 없으며 기존 앱을 삭제해서는 안 됩니다. v3.7 테스트 APK와의 서명·버전 조건은 맞지만 실제 업데이트 설치는 검증하지 않았습니다.
