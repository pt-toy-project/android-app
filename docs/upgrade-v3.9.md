# v3.9 시간표 보기 개선

기존 주간 표는 한 화면에 약 세 요일만 보이고 같은 파란색 수업 카드에 긴 이름·시간·강의실을 한꺼번에 넣어 읽기 어려웠습니다. 기본 글씨 크기에서는 주중 다섯 요일이 보이도록 칸을 좁히고, 수업마다 구분되는 차분한 색을 적용했습니다. 시간은 왼쪽 눈금에 표시하고 카드에는 이름과 강의실을 우선 배치합니다. 시간대를 위아래로 스크롤해도 요일 머리글은 남고, 주말은 좌우로 밀어 볼 수 있습니다. 글씨를 크게 설정한 경우에는 칸 폭을 넓히며 목록 보기로 전환할 수 있습니다.

화면 위의 큰 소개 문구와 여러 줄 버튼을 줄여 주간 표를 더 빨리 볼 수 있게 했습니다. 수업 추가는 상단 `+`에서도 열 수 있고, 목록 보기는 시간·수업명·강의실을 분리해 보여 줍니다. 에브리타임 공유 URL이나 CSV를 가져올 때는 저장 전에 주간 표 미리보기를 보여 주며, 수업을 누르면 전체 시간과 강의실을 확인할 수 있습니다. 취소하거나 가져오기 실패 시 기존 시간표는 그대로입니다.

393dp 다크 모드 화면에서 익명 예시 수업을 렌더링해 주간 표와 가져오기 미리보기를 확인했습니다: [주간 표](screenshots/v3.9-timetable-grid-night.png) · [가져오기 미리보기](screenshots/v3.9-timetable-import-preview-night.png). 320dp·큰 글씨 화면도 렌더링하고 요일 머리글이 시간 스크롤 중 같은 화면 위치에 남는지 검사했습니다.

검증: JVM 165개·SQLite 22개 통과, lint 오류 0개·경고 189개. 앱 APK와 기기 테스트 APK를 빌드하고 앱 APK의 서명·체크섬을 확인했습니다. 기기 테스트 APK는 실행하지 않았습니다. 세부 결과는 [빌드 정보](../downloads/v3.9-build-manifest.json)에 있습니다. DB 스키마는 v4 그대로이며 기존 루틴·완료 기록·코인·아이템·설정·시간표와 백업 형식은 바꾸지 않았습니다. 실제 기기에서의 화면·가져오기·업데이트 설치는 검증하지 못했습니다.

기존 v3.3 배포 APK와 클라우드 debug APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱과 데이터를 삭제하지 마세요. v3.8 테스트 APK와는 서명·버전 조건이 맞지만 실제 업데이트 설치는 확인하지 않았습니다.
