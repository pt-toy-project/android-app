# v3.4 — 계정 없이 이어가는 실천

이 문서는 v3.4 중간 검증 기록입니다. 현재 APK 경로에는 v3.5가 생성되므로 최신 결과·체크섬은 [v3.5 문서](upgrade-v3.5.md)를 확인하세요.

버전 3.4 / versionCode 7. 기존 3.3 대비 다음 다섯 가지를 개선했습니다.

1. **빠른 시작과 파일 백업**: 첫 화면에서 ‘계정 없이 시작’을 한 번 누르면 인물 목록으로 이동합니다. 사용 안내는 별도로 볼 수 있습니다. 백업과 복원 화면은 파일 저장·불러오기를 먼저 보여 주며, 등록되지 않은 Google 연결 버튼은 표시하지 않습니다. 기존 Google 코드는 유지합니다.
2. **탐색 복구와 작은 화면**: 검색 결과가 없을 때 검색어·목표·분야를 함께 초기화합니다. 탐색 필터와 결과를 한 영역에서 스크롤할 수 있어 큰 글꼴에서도 목록에 접근할 수 있습니다.
3. **홈의 집중 상태**: 진행 중인 타이머는 남은 분, 일시정지는 이어 하기, 종료 후 미완료 실천은 실천 확인 동선을 제공합니다. 타이머 종료로 코인을 지급하지 않습니다.
4. **집중 상태 복원**: 홈에서 타이머를 열어 초기화한 뒤 회전해도 선택한 실천을 유지합니다. 다른 실천으로 바꾸지 않겠다는 선택을 회전 후에도 유지합니다. 이전 예약 응답이 새 타이머 안내를 덮지 않도록 하고 초기화 후 낡은 안내를 지웁니다. 큰 글꼴에서는 타이머 숫자를 폭에 맞춥니다.
5. **알림 복구 동선**: 집중 알림이 꺼져 있거나 차단되었을 때 설정으로 이동하는 버튼을 제공합니다. 이미 요청했고 재요청 안내가 나오지 않는 알림 권한은 시스템 설정으로 연결합니다.

## 데이터 보존

DB 스키마·루틴 ID·완료 및 보상 규칙·백업 형식을 변경하지 않았습니다. 기존 마이그레이션·백업/복원·중복 보상 테스트를 포함한 전체 JVM 및 SQLite 검증이 통과했습니다. 실제 설치본 위의 데이터 보존 업데이트는 아래 서명 제한으로 미실행입니다.

## 검증 결과

- `:app:assembleDebug`: 성공
- `:app:testDebugUnitTest`: 136개 통과, 실패 0, 오류 0, 건너뜀 0
- `:app:lintDebug`: 오류 0, 경고 168개
- `:app:assembleDebugAndroidTest`: 성공 — 기기 테스트 APK 빌드이며 실제 계측 실행은 아님
- `python3 scripts/verify_database.py`: 21개 통과
- `apksigner verify --print-certs`: 성공
- `git diff --check`: 통과

추가한 9개 테스트는 계정 없는 즉시 시작, 필터 초기화·회전, 타이머 초기화·회전·재시작, 백그라운드 종료 후 홈 복귀, 종료 시 보상 미지급, 알림 설정 연결, 재요청 불가능한 권한 처리, 파일 백업 배치·파일 선택기, 작은 화면·다크 모드 렌더링을 검사합니다. 테스트 도구 설정 오류를 수정한 뒤 전체를 다시 실행한 최종 결과입니다.

렌더링은 Robolectric의 실제 Android View를 사용했습니다. `app/build/verification-screens/`에 일반 화면과 320×568dp·글꼴 200%·다크 모드 결과가 있습니다. 실기기 동작·TalkBack·스피커·진동·Doze를 검증한 결과는 아닙니다.
