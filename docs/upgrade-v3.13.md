# v3.13 하단 메뉴 정리

‘계획’ 탭은 ‘오늘’과 날짜·기록 기능이 겹쳤습니다. 하단 메뉴를 오늘 · 인물 · 시간표 · 상점 · 설정으로 바꾸고, 설정을 바로 열 수 있게 했습니다. 주간 시간표는 독립 탭으로 유지합니다.

기존 개인 계획은 삭제하지 않았습니다. 오늘 화면의 ‘내 계획 보기’로 개인 계획 화면에 들어가 생성·수정·실천할 수 있습니다. 날짜별 완료 기록과 코인은 오늘의 ‘월간 달력’에서 확인합니다. DB 구조와 저장 데이터를 바꾸지 않았습니다.

[오늘 화면](screenshots/v3.13-today-night.png) · [설정 화면](screenshots/v3.13-settings-night.png) · [빌드 정보](../downloads/v3.13-build-manifest.json)

실제 기기 설치·기기 계측 테스트는 실행하지 않았습니다. 기존 배포 v3.3 APK와 클라우드 debug APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱이나 데이터를 삭제하지 마세요.
