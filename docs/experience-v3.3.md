# 위인의 하루 3.3: 실천과 알림

버전 3.3 / versionCode 6. 인물 30명, 240블록, 510개 서브 퀘스트와 기존 ID·DB 버전 3을 유지한다. 새 인물을 추가하지 않는다. 기존 15장 사진·원래 크레딧을 변경하지 않으며 새 외부 이미지를 가져오지 않는다.

## 동작

- 설정 → 알림 → **10초 알림 시험**. 루틴 알림과 같은 소리/무음 채널을 사용한다. 정확한 알람 권한이 없으면 근사 예약이라는 안내를 표시하고 Android 지연 가능성을 설명한다. 알림 전역 해제·POST_NOTIFICATIONS·채널 차단을 존중한다. 시험은 완료 기록·코인·개별 루틴 알림의 중복 방지 기록을 변경하지 않는다.
- 오늘의 실천 상세 → **집중 타이머**. 5·10·25분 중 선택한다. 시간은 인물의 실제 연습 시간이라는 주장이 아닌 사용자 선택이다. 시작·일시정지·재개·다시 설정·실천 화면 복귀를 제공한다.
- 타이머 상태는 기기의 `focus_timer`에 저장하고 `elapsedRealtime`으로 계산한다. 화면 회전·프로세스 재생성·다른 화면 이동·기기 시각 변경에 영향을 받지 않는다. 재부팅은 마지막 저장한 남은 시간으로 일시정지한다. 전역 알림이나 권한이 꺼져 있어도 화면의 타이머는 동작하며 종료 알림 제한을 안내한다. Android가 근사 알람을 늦게 전달할 수 있다.
- 기기당 타이머는 하나다. 다른 실천으로 바꾸려면 남은 타이머를 교체할지 확인한다. 타이머를 끝내는 것만으로 퀘스트 체크·블록 완료·코인을 지급하지 않는다. 실천으로 돌아가 기존 완료 기능을 사용한다.
- 타이머·시험은 독립 PendingIntent 주소와 UUID를 사용한다. 이전/중복/너무 이른 이벤트는 현재 타이머를 종료하지 않는다. 일시정지·재설정은 종료 알림을 취소한다.
- 파일 복원이 성공하면 예전 루틴 ID를 따라가지 않도록 기기 타이머를 비운다. 타이머·시험 예약은 이동용 백업과 Android Auto Backup 대상에 포함하지 않는다.

## 화면

홈에는 진행 중인 집중 타이머의 재진입 버튼을 표시한다. 오늘 활성 일정 전체 완료 시 기록으로 연결되는 완료 카드를 표시한다. 목록은 제목을 먼저 보여주고 시간·인물·퀘스트 진행을 보조 줄에 둔다. 각 카드의 반복된 실천 보기 버튼과 긴 보상 문구를 제거하고 카드 자체를 상세 진입점으로 사용한다. 완료 버튼은 별도로 유지한다. 근거 칩과 접근성 라벨을 보존하고 큰 글꼴에서는 줄바꿈과 세로 배치를 허용한다. 뒤로/완료 아이콘은 기존 탭 벡터와 같은 두께의 자체 벡터다.

## 검증 기록

최종 결과는 README와 `downloads/v3-build-manifest.json`에 기록한다. Gradle 네 가지 작업·DB 검증과 Android 가상 기기 실행을 구분한다. `AlarmRuntimeTest`는 실제 AlarmManager 예약을 기다리며 수신기 함수를 직접 호출하지 않는다. 시험 알림, 두 출처의 루틴 알림과 실제 화면 연결, 중복 완료·중복 보상 방지를 확인한다. 전용 테스트 기기를 사용하며 테스트 전 DB/설정 사본을 복원한다. 실제 사용자의 휴대폰에서 실행하지 않는다.

Google 로그인/Drive의 프로젝트 등록값과 실제 실행은 여전히 별도 작업이다. 현재 APK는 계정 없이 사용 가능하며, Google 로그인이 성공했다고 표시하지 않는다. 새 라이브러리는 추가하지 않는다. 기존 역사 자료 접근 실패와 Google 약관 미확인 상태를 보존한다.
