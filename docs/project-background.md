# 프로젝트 배경과 초기 팀 구성

이 프로젝트는 캡스톤 디자인을 준비하며 팀 협업과 Android 앱 개발 과정을 경험하기 위해 시작한 토이 프로젝트입니다. 역사적 인물의 습관을 직접 실천하고 기록하는 것이 목표입니다.

| 역할 | 이름 | 초기 담당 업무 |
| --- | --- | --- |
| PM | 백승효 | 기획, Figma 화면 설계, 일정 관리 |
| Frontend | 박성호 | 프론트엔드 팀장 |
| Frontend | 박진영 | 프론트엔드 개발 및 Git 관리 |
| Frontend | 변주혁 | 프론트엔드 개발 |
| Backend | 백수현 | 백엔드 팀장 |
| Backend | 배재한 | 백엔드 개발 |
| Backend | 윤동규 | 백엔드 개발 |

Android 앱은 Kotlin과 XML로 작성했습니다. 초기 협업에는 Figma, GitHub, Discord, Notion을 사용했습니다.
