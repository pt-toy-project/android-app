# v3.16 내 계획을 오늘의 흐름에 연결

직접 만든 계획과 인물에게서 가져온 실천이 이제 **오늘**의 다음 행동과 시간순 목록에 함께 나타납니다. 오늘 화면에서 계획을 바로 만들거나 인물의 실천을 가져올 수 있고, 계획이 비어 있어도 인물에게서 가져오기 버튼이 보입니다.

같은 인물 실천을 두 경로로 담은 경우 오늘 목록에는 한 번만 표시합니다. 관리 화면에서는 두 루틴을 각각 수정할 수 있습니다. 완료 기록과 코인 지급은 기존 로컬 DB의 실천·날짜 규칙을 그대로 따르며, 같은 실천에 대한 보상은 한 번만 지급됩니다. DB 구조는 바뀌지 않았습니다.

[빌드·검증 정보](../downloads/v3.16-build-manifest.json) · [테스트 APK](../downloads/README.md)

실제 휴대폰 설치·기기 계측 테스트는 이 클라우드 환경에서 실행하지 않았습니다. 기존 배포 v3.3과 테스트 APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱과 데이터를 삭제하지 마세요.
