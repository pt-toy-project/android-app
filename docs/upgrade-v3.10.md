# v3.10 오늘의 시간표 카드 개선

‘오늘’ 화면에서 수업 두 개를 한 문장으로 이어 붙여 이름과 시간을 읽기 어려웠습니다. 이제 수업마다 시간, 이름, 강의실을 다른 줄에 표시합니다. 앞의 두 수업 다음에는 나머지 수업 개수를 보여 주고, ‘전체 시간표 보기’로 상세 화면을 열 수 있습니다. 수업이 없는 날에는 빈 상태를 표시합니다.

달력에서 다른 날짜를 고르면 해당 요일의 수업과 날짜 제목을 표시합니다. ‘전체 시간표 보기’를 누르면 선택한 날짜가 속한 주가 열립니다. 큰 글씨에서는 날짜와 달력 버튼을 세로로 배치합니다. 320dp 화면과 큰 글씨 화면을 렌더링해 확인했습니다: [기본](screenshots/v3.10-today-timetable-compact.png) · [큰 글씨](screenshots/v3.10-today-timetable-large-font.png).

DB 스키마와 저장 데이터는 변경하지 않았습니다. 로그인이나 새 권한도 필요하지 않습니다. JVM 167개, SQLite 22개, lint 및 APK 빌드 결과는 [빌드 정보](../downloads/v3.10-build-manifest.json)를 참고하세요. 실제 휴대폰 화면·업데이트 설치·기기 계측 테스트는 실행하지 않았습니다.

기존 배포 v3.3 APK와 이 클라우드 debug APK는 서명이 달라 덮어쓰기 설치할 수 없습니다. 기존 앱이나 데이터를 삭제하지 마세요.
