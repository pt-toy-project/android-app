Robolectric/Android 35에서 실제 Activity와 View를 생성하고 클릭·DB 동작·Native Graphics 렌더링을 실행했습니다. 하루 시작 시 8블록 생성, 완료 후 1/8 진행률·10코인, 개인 계획 저장과 입력 검증, v1 파일 업그레이드를 확인했습니다. 시뮬레이션과 실제 기기 실행은 구분합니다. 구체적인 실행 범위는 [UI 개편 검증](../docs/ui-overhaul-validation.md)을 참고하세요.

기존 사진 15장·기본 아바타·이미지 크레딧 파일은 그대로이며 사진/아바타 용량 증가 0 B입니다. AI 이미지·새 외부 이미지·신규 폰트 작업은 없습니다. 인물 30명·240블록은 유지합니다. 자료 URL 47개를 실제 재요청했지만 CONNECT 403으로 실패해 모든 하루 블록은 현대 적용 제안으로 표시합니다.

파일 다운로드 후 브라우저/파일 앱의 설치 권한을 허용하여 새 테스트 기기에 설치합니다. 비공개 저장소라면 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다. 코인은 현금 가치가 없는 로컬 포인트이며 로그인·서버 동기화·현금 결제는 없습니다.

체크섬 파일: [android-app-v3-debug.apk.sha256](android-app-v3-debug.apk.sha256). 두 파일을 같은 디렉터리에 내려받아 확인합니다.

```bash
sha256sum --check android-app-v3-debug.apk.sha256
```
